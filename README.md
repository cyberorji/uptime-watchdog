# uptime-watchdog

> Web siteleri için basit self-hosted uptime izleme aracı

Bu depo aktif geliştirme altındadır. Amaç; Linux, Windows ve Termux üzerinde kolay kurulabilen, açık kaynak ve topluluk katkısına uygun bir başlangıç sunmaktır.

## Durum

**Başlangıç sürümü / scaffold.** Özellikler aşamalı olarak eklenecektir.

## Kurulum

### Linux

```bash
git clone https://github.com/cyberorji/uptime-watchdog.git
cd uptime-watchdog
```

### Windows (PowerShell)

```powershell
git clone https://github.com/cyberorji/uptime-watchdog.git
Set-Location uptime-watchdog
```

### Termux

```bash
pkg update
pkg install git
git clone https://github.com/cyberorji/uptime-watchdog.git
cd uptime-watchdog
```
